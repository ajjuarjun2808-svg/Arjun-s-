Mandelbrot Fractal

The Mandelbrot set is generated using the iterative complex number formula:

Zn+1 = Zn2 + C

For each pixel, we check if the orbit escapes to infinity. Colors are determined by how fast the sequence escapes.

Controls:
• Move mouse to position zoom preview.
• Scroll wheel to resize zoom box.
• Click to zoom in.
